## 已确认的共用缺陷

- modal 提交完成后无条件清空根节点，导致 WordPress 一次性凭据等后续弹窗消失。
- navigate 返回异步函数但未 await，页面请求失败绕过统一错误提示。
- 后台任务仅等待 8 分钟，而服务端单条命令允许 20 分钟，且没有超时结果提示。
- Compose 删除仅删除项目目录，遗留 deployments/<id>.json，且运行容器继续存在。
- appActions 在更新和卸载均未声明时仍会提供错误操作。
- 注册表可与内置应用同 ID，列表和实际执行对象不一致。
- README 宣称的部分应用并未实际内置；需要以真实配方和验证结果更新文档。

## 验证边界

- 应用配方的结构测试不等同于镜像拉取、首次初始化、数据迁移与备份恢复的完整验收。
- 镜像回滚只恢复容器镜像，不回滚应用数据库或持久化卷；升级前需另行备份数据。
- 测试机已有业务且磁盘空间有限，未批量安装全部应用或执行破坏性的 SSH、防火墙、数据库恢复测试。
- 测试机模板关闭自动接管防火墙以保留现有网络策略；该模板不应直接代替通用新机安装配置。
